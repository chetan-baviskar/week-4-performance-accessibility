# FocusFlow — Week 3 JavaScript Task

A responsive interactive productivity dashboard made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — semantic page structure and UI components.
- `style.css` — responsive styling, animations, light/dark themes and reduced-motion support.
- `script.js` — DOM updates, task actions, progress calculations, menu toggle, theme persistence and form validation.
- `REPORT.md` — technical implementation notes.

## Run locally
Open `index.html` in a modern browser. No build tools or server are required. Google Fonts are loaded from the web; system fallbacks are included.

## Interactive features
1. Add tasks with input validation.
2. Mark tasks complete/incomplete and delete tasks.
3. Automatically update completion counts and progress indicators.
4. Clear completed tasks.
5. Toggle and remember light/dark theme using localStorage.
6. Responsive mobile navigation.
7. Contact form validation for name, email and message.
8. Toast feedback for user actions and a dynamically displayed date.

## Notes
The contact form is a front-end demonstration only. It validates inputs but does not send or store messages on a server.
